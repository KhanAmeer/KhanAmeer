## 🚀 Featured Projects

### 📊 Startup Funding Analysis (SQL + Power BI)

An end-to-end data analytics project that analyzes startup funding trends using Microsoft SQL Server and presents business insights through an interactive Power BI dashboard.

#### Highlights

- Analyzed 1,016 startup funding deals
- Built complex SQL queries using CTEs and Window Functions
- Performed Exploratory Data Analysis (EDA)
- Calculated statistical metrics including Median and Gini Coefficient
- Identified funding inequality and sector trends
- Created an interactive Power BI dashboard
- Developed annual funding projections using historical data

**Tech Used**

`SQL Server` `Power BI`
